# Salvare un'istantanea

## Git Status
Mostra lo stato dei file nella working directory.

```bash
git status
```

## Git Add
Contrassegna i file nella staging area.

```bash
git add .
git add nomefile
```

## Git Commit
Registra un'istantanea del repository.

```bash
git commit
git commit -m "commento x questo cambiamento"
```

## Git Log
Visualizza l'elenco del nostro archivio contenente tutte le istantanee che abbiamo registrato.  

```bash
git log
git log --stat (x avere anche nomi file)
git log --oneline (registro sintetico locale)
git log --oneline --all (reg sint. totale che tiene conto anche dei cambiamenti sui remote e non solo in locale)
git log --oneline --all --graph
  (mostra l'elenco dei rile con i bracci (branch) con una sorta di grafico che mostra quanti branch ci sono e quali
file e modifiche sono associate ad ogni branch)
```

### Esempio
```bash
git status
git add .
git commit -m "Aggiunta gestione errori"
git push
```

# Comandi e ripensamenti

## Git Commit --amend
```bash
git commit --amend
```
Sovrascrive il commit precedente perdendone le informazioni poco importanti, facendone un merge con quest'ultimo commit.  
(ne fonde 2 in 1) Utilizzato per piccole modifiche, ad esempio per aggiungere il nome alla licenza LICENCE.txt.
Utile perché avere tante righe di commit potrebbe aggiungere un po' di confusione.

## Git Restore
```bash
git restore <file>
git restore --staged <file>
```
Elimina gli ultimi cambiamenti di quel file portandolo alla versione precedente 
(è un undo a livello di file salvato, lo porta al salvataggio e commit precedente)
Il primo comando lavora nella Working Area, il secondo nella Staging Area.

## Git Diff
```bash
git diff
```
Mostra i file modificati e le righe modificate.

# Repository remoto

## Git Remote
```bash
git remote add origin https://github.com/davoliojobGIT/3.VIDEO_CORSO_GIT.git
git remote
git remote -v
git remote show origin
git remote rename origin org
git remote rm backup
```

## Git Push
```bash
git push origin master
```

## Git Fetch
```bash
git fetch --all
```
Aggiorna le informazioni sui repository remoti senza fare merge.

## Git Pull
```bash
git pull origin master
```
Scarica e integra le modifiche remote.

# Merge e conflitti

## Git Merge
```bash
git merge nome_branch
```

### Regole principali
- Le eliminazioni vengono propagate se il file non è stato modificato altrove.
- Le modifiche vengono integrate se non ci sono cambi concorrenti.
- In caso di modifica della stessa area del file viene generato un conflitto.

## Analisi conflitti
```bash
git diff nomefile
```

---

# Tipi di merge

## Fast Forward
```text
A --- B --- C (main)
                           D --- E (feature)
```

```bash
git merge feature
```

Nessun commit di merge e nessun conflitto.

## Three Way Merge
Genera un commit di merge e può produrre conflitti.

```bash
git merge feature
```

Dopo la risoluzione:

```bash
git add app.txt
git commit
```

# Gestione rami remoti

```bash
git push origin minestrone
git push origin minestrone:mine_cond
git push origin --delete minestrone

git fetch --all
git pull origin minestrone

git branch --delete minestrone

git checkout -b minestrone origin/minestrone
```

# Rifondazione di un ramo (Rebase)

```bash
git rebase master
```

Permette a un branch di acquisire le modifiche introdotte successivamente sul ramo principale.
